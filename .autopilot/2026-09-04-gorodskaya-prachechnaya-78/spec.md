# Спецификация: Сайт «Городская прачечная 78»

## Задача

У владельца прачечной/химчистки «Городская прачечная 78» (СПб, ул. Яхтенная, 28) сейчас одностраничный лендинг на Яндекс.Бизнесе. Нужен современный многостраничный промо-сайт (8 страниц) с анимациями, адаптивный, на чистом HTML/CSS/JS, за который интересно наблюдать и который вызывает доверие. Реальные цены, контакты, услуги — из референсных PDF владельца.

## Решение

8 статических HTML-страниц с общим `style.css` и `script.js`. Header/footer единые. Анимации на IntersectionObserver (scroll fade-in, parallax, hover-эффекты, счётчики, лайтбокс, бургер-меню). Мобильная адаптивность через media-queries. Реальные цены из PDF-прайсов владельца. Плейсхолдеры для фото. Карта — iframe Яндекс.Карт.

### Цветовая палитра

- Основной: `#1a56db` (синий), `#3b82f6` (голубой)
- Фон: `#f0f7ff` (светло-голубой), `#ffffff` (белый)
- Акцент: `#f59e0b` (янтарный — кнопки, бейджи акций)
- Текст: `#1e293b` (тёмно-серый), `#64748b` (средний серый)
- Чистота: `#ecfdf5` (светло-зелёный — преимущества)

## Решения по реализации

### Стек

- **HTML5** — семантическая верстка: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<article>` для отзывов
- **CSS3** — общие стили + адаптивность через `@media (min-width: 768px)` и `@media (min-width: 1440px)`, CSS Custom Properties для цветов
- **Vanilla JS** — IntersectionObserver для scroll-анимаций и счётчиков, обработка форм, лайтбокс, бургер-меню, parallax

### Структура файлов

```
index.html
about.html
services.html
prices.html
promo.html
reviews.html
gallery.html
contacts.html
css/
  style.css        — все стили, включая компоненты и адаптивность
js/
  script.js        — все интерактив и анимации
images/
  (placeholder — placehold.co используется inline через URL)
```

### Данные

- **Цены**: реальные из PDF-прайсов владельца (файлы в `reference/`). Приоритет для таблиц — основные позиции по каждой категории. Ссылка «уточняйте по телефону» для сложных/индивидуальных услуг.
- **Адрес**: 197082, Санкт-Петербург, Приморский р-н, ул. Яхтенная, д. 28, строение 1, помещение 32Н (пересечение с ул. Оптиков)
- **Режим работы**: ежедневно 9:00–21:00
- **Отзывы**: 4 реальных из брифа (verbatim)
- **Бонусная программа**: 1% с заказа + 2% в «Счастливые часы» (9:00–15:00), действует 20.01.2026–31.12.2026

### Анимации (детали)

| Эффект | Реализация | Триггер |
|--------|-----------|---------|
| Scroll fade-in | `opacity: 0 → 1` + `translateY(30px → 0)` | IntersectionObserver, threshold 0.1 |
| Parallax hero | `transform: translateY(scrollY * 0.3)` | scroll event + requestAnimationFrame |
| Hover карточки | `box-shadow` + `translateY(-4px)` + `scale(1.02)` | CSS `:hover`, transition 0.3s |
| Счётчики | `requestAnimationFrame`, от 0 до значения за 2s | IntersectionObserver одноразово |
| Лайтбокс | `opacity: 0 → 1` + backdrop blur/fade | клик по фото, закрытие по Escape/оверлею |
| Бургер | `max-height: 0 → 100vh`, transform | клик по иконке |
| Бейдж пульс | CSS `@keyframes pulse` (scale 1 → 1.05 → 1) | бесконечный цикл 2s |
| Page fade-in | `body { animation: fadeIn 0.3s }` | DOMContentLoaded |

## Границы и швы

Этот проект — статический сайт без API, без бэкенда, без базы данных. Один субагент строит весь сайт целиком — границы между модулями минимальны.

| Модуль | Владеет | Выставляет | Прячет |
|--------|---------|-----------|--------|
| HTML-страницы (8 шт.) | разметку, семантику, ссылки | class-атрибуты для CSS/JS | структуру (CSS/JS не знают о DOM) |
| `style.css` | все визуальные стили | CSS Custom Properties (переменные цветов) | медиа-запросы, анимации |
| `script.js` | весь интерактив и анимации | обработчики событий | логику IntersectionObserver, параллакса |

Швы для проверки:
- **Навигация**: все 8 страниц ссылаются друг на друга корректно (innerHTML в header/footer)
- **CSS**: все страницы подключают style.css, классы совпадают
- **JS**: script.js загружается на всех страницах, не падает на страницах без определённых элементов (guard checks: `if (element)`)

## Вне рамок

| Требование | Почему не сейчас |
|-----------|-----------------|
| Реальные фото (не плейсхолдеры) | владелец не предоставил; плейсхолдеры можно заменить позже |
| Реальная форма обратной отправки | бриф требует «просто UI, без реальной отправки» |
| Оплата/заказ онлайн | не упомянуто в задаче |
| Админка для управления контентом | не упомянуто; сайт статический |
| Многоязычность | не упомянуто, аудитория — РФ |
| SEO-оптимизация (schema.org, meta) | можно добавить позже; приоритет — контент и дизайн |
| Адаптивность для планшетов в отдельном breakpoints | mobile-first покрывает: 375px → 768px → 1440px |
