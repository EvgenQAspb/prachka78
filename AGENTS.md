## Правила для агента

### Общее
- Все тексты — на русском языке.
- Не придумывать цены, отзывы или контакты, которых нет в референсе — уточнять у пользователя, а не выдумывать.
- Сохранять реальные контактные данные и юридическую информацию точно как указано выше.
- Дизайн — не копировать один в один визуально с оригинала (это шаблон Яндекс.Бизнеса), а сделать современный, чистый лендинг: адаптивный, быстрый, с хорошей типографикой.
- Мобильная версия обязательна (много клиентов заходят с телефона по прямой ссылке в Telegram/WhatsApp).

### Код
- TypeScript strict mode.
- Компоненты — маленькие, переиспользуемые, по одному на файл.
- Изображения — через next/image, с alt-текстами на русском.
- Семантическая верстка (header, nav, main, section, footer), доступность (a11y): контрастность, aria-label для иконок-ссылок.
- SEO: title, meta description, Open Graph теги, микроразметка schema.org (LocalBusiness / LaundryOrDryCleaner) с адресом, телефоном, часами работы.

### Git / коммиты
- Коммиты — маленькие и осмысленные, на русском или английском (по договорённости), в повелительном наклонении: «Добавить секцию отзывов».
- Не коммитить .env и ключи API.

### Тестирование и проверка
- Перед сдачей — проверить сборку (`npm run build`), отсутствие ошибок линтера (`npm run lint`).
- Проверить адаптивность на мобильных ширинах (375px, 768px, 1440px).
- Проверить, что все ссылки на телефон/мессенджеры кликабельны (`tel:`, `https://wa.me/`, `https://t.me/`).

### Что уточнять у пользователя, а не решать самому
- Финальный список услуг и цен для каталога (в референсе каталог пустой/не распарсен).
- Нужна ли форма заказа/обратный звонок и куда должны приходить заявки.
- Хостинг/домен (сейчас сайт на поддомене clients.site).
- Нужны ли реальные фото помещения/работ или заглушки.

## Запрещено
- Не использовать вымышленные отзывы, фото людей или логотипы конкурентов.
- Не менять юридическое название организации и реквизиты без прямого указания пользователя.
- Не отправлять никакие данные пользователей на сторонние сервисы без явного согласия/настройки.

## Ключевые решения (неочевидно, уже укусило)

- **Данные вшиты в код.** Реальные контакты, цены, юр.реквизиты и режим работы захардкожены в HTML. Не «портировать из интерфейсов» — просто брать как есть: тел +7 (950) 039-89-88, ул. Яхтенная 28, ежедневно 9:00–21:00, VK vk.ru/prachka78spb, ИП Клипачев И.В., ОГРНИП 323784700192634, ИНН 540543766407.
- **Фото — плейсхолдеры** placehold.co URL inline (например `https://placehold.co/600x400/3b82f6/ffffff?text=...`), локальных файлов изображений нет.
- **Форма — UI без бэкенда.** `.form` при сабмите показывает `.form__success`, ничего никуда не отправляет.
- **Все функции в JS с guard-checks** (проверяют наличие элементов), поэтому один `script.js` работает на всех страницах, даже если на конкретной странице нет соответствующего блока.
- **Windows:** `python3` тут — `python.exe`; для сервера используй `python3 -m http.server` в корне без версии. Современный `node` есть (v26).
- **Не менять стек.** Проект изначально задумывался на Next.js (см. правила выше вне маркеров), но фактически реализован на чистом HTML/CSS/JS — не переводить на фреймворки без явного запроса.

## Интерактив (js/script.js)

Бургер-меню (`.burger`/`.nav`), scroll-reveal через IntersectionObserver (`.reveal` → `.is-visible`), анимированные счётчики (`[data-count]`), parallax hero (`.hero__bg`), page-fade при переходе по `.html`, лайтбокс галереи (`.gallery__item`), форма (UI), таймер акции (`#promoTimer`, до 31.12.2026), год в футере (`#year`).

## Стили (css/style.css)

CSS Custom Properties в `:root`: `--color-primary: #1a56db`, `--color-accent: #f59e0b`, `--color-text: #1e293b`, `--color-bg: #f0f7ff`, плюс переменные теней/радиусов/контейнера/высоты хедера. Mobile-first, breakpoints 375px → 768px → 1440px.

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

Если работа продолжается — скажи «продолжи автопилот»: состояние поднимется
из `.autopilot/state.js`, переспрашивать ничего не нужно.
